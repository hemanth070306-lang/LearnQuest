📖 Mission 3: Python Loops

Loops allow us to repeat a block of code multiple times.

A for loop is commonly used when we know how many times we want to repeat something.

for i in range(5):
    print(i)

This prints the numbers from 0 to 4.

Python also has a while loop, which continues while a condition is true.
